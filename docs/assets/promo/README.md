## Setting the GitHub social preview (manual)

GitHub does not read the social preview from the repository; it must be uploaded by a repository admin:

1. Open the repository → **Settings** → **General**.
2. Under **Social preview**, click **Edit** → **Upload an image…**
3. Choose `war-of-machines-github-social-preview-1280x640.png` and save.

**BG:** Settings → General → Social preview → Edit → Upload an image… → изберете `war-of-machines-github-social-preview-1280x640.png`. Това става ръчно; файлът в хранилището сам по себе си не задава превюто.
