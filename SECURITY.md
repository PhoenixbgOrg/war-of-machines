# Security / Сигурност

**EN.** Please report security issues privately by email to **info@ritualforgelabs.com**. Do not open a public issue for vulnerabilities. **Never post API keys, passwords, databases, logs or real conversations** in issues, emails or screenshots; if a key was exposed, revoke it at your provider immediately. War of Machines stores API keys only in your system keyring (or environment variables) and has no telemetry.

**BG.** Съобщавайте за проблеми със сигурността лично на **info@ritualforgelabs.com**, а не в публичен issue. **Никога не публикувайте API ключове, пароли, бази данни, логове или реални разговори** — нито в issues, нито в имейли или снимки; ако ключ е изтекъл, анулирайте го веднага при доставчика. War of Machines пази ключовете само в системния keyring (или в променливи на средата) и няма телеметрия.
